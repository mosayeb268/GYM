# سیستم عامل کینتیک کر (Kinetic Care OS)
## پلتفرم یکپارچه مدیریت کلینیک ورزشی و حرکات اصلاحی دکتر قدم‌پور

پروژه **Kinetic Care OS** سیستم جامع سازمانی و نرم‌افزاری اختصاصی جهت مدیریت فنی، علمی، بالینی و مالی «کلینیک ورزشی و حرکات اصلاحی دکتر قدم‌پور» است.

---

### مشخصات کلیدی پلتفرم:
1. **بومی‌سازی ۱۰۰٪ فارسی:**
   - چیدمان اجباری راست‌به‌چپ (RTL Layout) با معکوس‌سازی جهت‌های ناوبری.
   - قلم استاندارد **وزیرمتن (Vazirmatn)** در تمام اوزان متریال ۳ با تنظیم دقیق ارتفاع خطوط (`lineHeight`).
   - موتور تبدیل ارقام و مبالغ به زبان فارسی و ارز تومان با جداکننده سه‌رقمی.
   - موتور اختصاصی محاسبات گاه‌شماری هجری شمسی (جلالی) و تاریخ‌گزین شمسی در Compose.

2. **مدیریت باشگاه تجاری:**
   - صدور اشتراک‌های زمانی، جلسه‌ای و ترکیبی.
   - بلیط هوشمند تردد با بارکد پویای رمزنگاری شده HMAC-SHA256 (تغییر هر ۱۵ ثانیه جهت ممانعت از جعل و تقلب).
   - سیستم فریز / تعلیق هوشمند اشتراک.

3. **کلینیک فیزیولوژی ورزشی و حرکات اصلاحی (تحت نظارت دکتری فیزیولوژی):**
   - ارزیابی پاسچرال فوتوگرامتری با خطوط شاقولی شطرنجی و سنسور تراز ژیروسکوپ CameraX.
   - موتور گیت ایمنی بیومکانیک (قفل حرکات متداخل با ناهنجاری‌های اسکلتی-عضلانی).
   - موتور رگرسیون سازگار شونده بر مبنای مقیاس دیداری سنجش درد (VAS).
   - سیستم جایگزینی واحدهای درشت‌مغذی و تبادل غذایی (Food Exchange System).

---

### ساختار دایرکتوری‌ها:
- `/android`: اپلیکیشن اندروید (Jetpack Compose + Clean Architecture + MVI)
- `/backend`: وب‌سرویس و موتور هسته سیستم (Node.js / TypeScript / Prisma / Redis)
